A writing-focused website has a straightforward job: make words easy to find and pleasant to read. Most of those words do not change between two consecutive visits.

## Build the page ahead of time

Static generation produces HTML during a build. The hosting layer can serve those files without running an application server for every request.

This does not remove every operational concern. Builds, dependency updates, accessible markup, and correct URLs still need attention. It does reduce the number of moving parts in the request path.

## Add interaction where it helps

A language filter can be a small browser script. Reading an article should not require that script to run. Keep the initial document useful and add behavior to it.

## Know when to change the default

Personalized data, authenticated workflows, and live information may need a server. Choose those capabilities when the product needs them, and keep content pages simple when it does not.
